# UiSE — Universidade Internacional de Sistemas e Educação

> Experiência digital institucional desenvolvida em equipe como projeto acadêmico de UX/UI.

## Sobre

A **UiSE (Universidade Internacional de Sistemas e Educação)** é uma instituição de ensino superior fictícia criada pela equipe a partir de um briefing acadêmico originalmente proposto para uma escola técnica.

O projeto foi expandido para simular o desenvolvimento de uma solução digital em um contexto profissional, envolvendo desde a concepção da instituição e sua identidade visual até a estruturação da experiência e da interface do usuário.

## Objetivo

Criar uma plataforma institucional moderna, clara e intuitiva, aplicando princípios de **UX/UI, arquitetura da informação, design de interfaces e desenvolvimento web**.

O projeto também busca reproduzir etapas presentes no fluxo de trabalho de equipes de tecnologia e design.

## Projeto

O desenvolvimento contempla:

- **UX** — pesquisa, estruturação e experiência do usuário
- **UI** — design visual e componentes de interface
- **Identidade visual** — conceito, elementos gráficos e comunicação
- **Arquitetura da informação** — organização e hierarquia do conteúdo
- **Prototipação** — definição e validação das interfaces
- **Desenvolvimento web** — implementação da solução
- **Responsividade** — adaptação para diferentes dispositivos
